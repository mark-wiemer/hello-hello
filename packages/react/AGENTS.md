# Hello React

Before changing this app, read [the package README](readme.md) for its purpose and
tooling.

- Test component and hook behavior with Vitest and React Testing Library in
  `src/`; use accessible roles and names when querying rendered UI.
- Put browser-level flows in `tests/` and use Playwright.
- Run `npm run validate` from this package before handing off changes. It checks
  formatting, lint, TypeScript, unit tests, and browser tests.
