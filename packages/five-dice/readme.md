# Five Dice

A Yahtzee-like dice poker game.

## Project structure

- FiveDice: Production code. Executed via:
  ```sh
  dotnet run --project FiveDice
  ```
- Test: Test project. Executed via:
  ```sh
  dotnet run --project Test
  ```
